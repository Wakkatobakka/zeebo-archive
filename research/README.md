# Research continuity

Read ../ARCHIVE_STANDARD.md before working. Keep search records here as JSONL or a readable table, using actual searches only. For each record include date, entry IDs, topic, title variants, language, query or search avenue, site/URL, outcome, supporting evidence and next action. Record blocked access and unsearched leads separately from unsuccessful searches. Sources inherited from older versions have no reconstructed search history.

Suggested outcomes: useful, duplicate, inaccessible, irrelevant, disproven. Suggested coverage states: inventory only; research in progress; researched with remaining gaps; reviewed against the standard. State the basis of a review rather than inferring it from bibliography size.
