ZEEBO / METHODS & CREDITS

About the archive

A true archive of the game and its history, not just a file.

The collection

The original inventory contains 56 games, five applications and 20 tools or reference records. The 61 numeric game/app IDs represent 68 title packages. Variants stay grouped under the existing record URLs.

All 88 source files, direct-member inventories, source paths and fingerprints are retained. IMICRO3D component ID 12875, bundled with Action Hero 3D, remains part of that package rather than a separate game.

Game histories

Interviews, developer portfolios, credit records, announcements and contemporary coverage are cited alongside each entry. Direct quotations retain the original wording and identify the speaker, publication and translation where relevant.

Original arcade, console or phone teams are distinguished from Zeebo porting teams. A contributor’s edition is shown with the credit. Historical announcements describe plans at the time; entries distinguish those plans from documented releases.

Images and original documents

Images have captions, source links and contributor or reproduction credits. Emulator captures are labelled as such. The image collection includes creator portfolios, game interfaces, promotional material and later photographs. Captions distinguish released-game images, interface artwork, emulator captures, portraits and conference photographs; they do not imply that these are early prototypes or workplace photographs.

The undated Zeebo Brasil game guide contains 14 scanned spreads. The existing guide descriptions cover 39 title IDs and retain the exact scan locators. Full-resolution scans remain linked at the original source.

File records and verification

The original research matched all 88 source files to the sizes and SHA-1 values in the Internet Archive manifest. SHA-256 values were measured for source files and direct regular archive members. Those records are unchanged in this edition.

Internal BAR, PAK and GGZ containers were not exhaustively decoded. Content-multiset fingerprints compare file bytes and sizes while ignoring names and order.

No game or developer utility was executed for this catalog. File identification and gameplay testing remain separate.

Preservation credits

OpenZeebo’s compilation and ID mapping are dated 23 October 2011. The Internet Archive collection was added on 1 March 2021. Original preservation credits belong to OpenZeebo and the Internet Archive community; the printed guide is credited to Zeebo Brasil S.A.

Wakka assembled this independent archive. Individual entries identify the developers, artists, interviewers, reviewers and researchers whose work is used.

Corrections and additions

Send a correction or source with the title or record ID and a supporting reference. Wakka reviews changes before publication.
