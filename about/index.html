CONTEXT MATTERS, TOO

The games had names.
The archive should, too.

Behind the six-digit filenames is an unusual console, a community preservation effort, and a printed guide full of games worth remembering.

A console with mobile roots

Zeebo was a television console built around Qualcomm mobile technology. Games arrived over a 3G connection rather than on discs. In a May 2009 interview, its executives described an effort aimed at middle-class households in emerging markets, with Brazil as the initial launch market. Read the contemporary interview ↗

From a storefront to a surviving collection

The OpenZeebo readme dated 23 October 2011 describes a preservation compilation and maps numeric application IDs to game and system-app names. Its claim to contain every release is a statement by that historical source; this catalog counts the files actually supplied.

The Internet Archive item Zeebo (All Games + Dev Tools) was added on 1 March 2021. Its original collection is credited here, rather than presented as a new recovery by this project. View the original collection ↗

What the four supplied archives contain

The uploaded copies yield 61 game/app IDs in 68 title packages. Those include system applications as well as games. Shared IDs are grouped on one page, retaining distinct packages. IMICRO3D, component ID 12875 inside Action Hero 3D, is not counted as an additional game.

There are also 16 developer/support files, three readme/ID-list records and one printed-guide record. Together these make 81 browsing records and 88 source files. Material under the BREW tools folder is not automatically classified as a Zeebo retail release.

A printed guide puts the names in context

The undated Zeebo Brasil S.A. Guia de Jogos contains 14 scanned spreads. Original brief English summaries of its product descriptions accompany 39 title IDs. Each page gives its exact scan filename so the description can be checked.

The guide describes advertised products; it does not authenticate the revision of a surviving executable. Scans and original documents remain linked at their source.

How the evidence was checked

All 88 source files match a file size and SHA-1 in the Internet Archive file manifest embedded in the supplied ZIP. SHA-256 values were measured independently for every source file and every direct regular archive member.

The member inventory excludes directories from file counts. Containers inside the packages, including BAR, PAK and GGZ, were not exhaustively decoded. A content-multiset fingerprint compares file sizes and bytes while ignoring names and order; it is not a folder-layout equivalence claim.

Can these files be played?

This is a discovery and research catalog. No preserved game or developer utility was executed while assembling it. A file record does not establish compatibility, complete gameplay or continued availability of original online services.
