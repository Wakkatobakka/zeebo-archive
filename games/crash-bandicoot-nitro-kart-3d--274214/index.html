The game

Crash Bandicoot Nitro Kart 3D puts the series’ characters into item-filled kart races. The Zeebo guide advertises courses that run from underwater environments to space.[2]

Development

Polarbit made the original mobile game using its Fuse technology. Tectoy Digital adapted it for Zeebo. Tiago Tex Pine and Hugo Faria handled production; the programming credits name Vitor Picanço do Amaral, Tiago Monteiro Fernandes, Leonardo Loures Lopes and Bruno Evangelista.[3]
