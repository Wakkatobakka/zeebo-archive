The game

Galaxy on Fire puts the player in a spacecraft as a Terran mercenary fighting the Vossk.[2]

Development

Fishlabs adapted Galaxy on Fire using its ABYSS engine. Michael Schade explained which versions supplied the code and artwork:[3]

The first Zeebo builds ran too slowly. The team reduced assets and reorganised textures, eventually reaching roughly four times its initial frame rate.[3]

Television output introduced other constraints. Strong colours could bleed and fine horizontal lines could flicker; the absence of OpenAL required changes to the sound engine.[3]
